03 — Projects

Engineering Work

Project 01 · Research
Indoor Warehouse Drone Navigation & Inventory Management System
Designed and developed a complete autonomous drone system for GNSS-denied indoor environments, achieving high-precision localization and real-time inventory automation.
  • Implemented UWB-based localization using trilateration with Kalman filtering for noise reduction
  • Achieved >95% positioning accuracy in indoor GNSS-denied environments
  • Developed QR-based inventory tracking integrated with MySQL database (~98% detection accuracy)
  • Designed and tested quadcopter prototype with ~800g payload capacity
  • Conducted MATLAB/Simulink simulations for flight dynamics, payload optimization, and system validation
  • Engineered full pipeline: localization → perception → control → data system
UWB Localization MATLAB / Simulink OpenCV MySQL Embedded Systems Kalman Filter QR Detection

Raspberry Pi OpenCV Image Processing Camera Calibration

Autonomous Drone — Circle Detection Navigation
Navigation system using Tello drone and OpenCV. Drone detects circular obstacles via Hough Circle Transform and autonomously aligns and maneuvers through them using image-based control logic.
